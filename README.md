# CPP_Refresh

C++ refresher notes with a systems-programming focus — written from the perspective of a Java engineer revisiting C++ for low-level and Oracle infrastructure work.

## Contents

- `DAY01/`
  - `Java_With_C++_Int.md` — How Oracle Java products interact with C++: Java as the orchestration layer, C++ for system-level work
  - `OracleC++Experience.md` — Oracle provisioning and identity components implemented in C/C++, and why C++ is chosen for them
- `DAY02/`
  - `C++NativeCallsFromJava.md` — Linux native system calls used by Oracle C++ host agents (OEM Agent, Clusterware, Database)
  - `ABoutFork.md` — Understanding `fork()` in Linux: process duplication, parent vs. child execution
- `Pointers.md` — Comprehensive guide to pointers and memory management: declaration syntax, `const char*`, pointer arithmetic, dynamic allocation, smart pointers

## Topics covered

Pointers and memory management, Linux system calls (`fork()`), JNI/native interop concepts, why C++ matters in Oracle's Java-centric products.
